# WS-DREAM QoS Statistical Analysis

## Overview
Statistical analysis of the **WS-DREAM QoS dataset** using Python.  
The analysis focuses on:

- Response Time (RT)
- Throughput (TP)

## Analysis Covered
- Data preprocessing
- Descriptive statistics
- Moments and expectation
- Probability distribution fitting
- MLE and Method of Moments
- Confidence intervals
- Hypothesis testing
- Normality and outlier analysis
- Pearson and Spearman correlation
- Central Limit Theorem
- Expectation-Maximization (EM)
- Gaussian Mixture Model

## Tools
- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
WS-DREAM QoS Dataset:  
https://github.com/wsdream
